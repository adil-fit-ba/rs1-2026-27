Postojeći projekat na Clean Architecture

Isti kod i ista baza podataka, raspoređeni u četiri projekta.

Polazna tačka je projekat nakon V04: jedan projekat MojaApp.API s CQRS-om (MediatR, FluentValidation). U pet koraka on postaje Domain, Application, Infrastructure i API, kao starter za seminarski rad. Poslije svakog koraka build prolazi, pa se svaki korak može posebno commitati.

Primjer je MojaApp. Za vlastiti projekat MojaApp u komandama i namespaceovima zamijenite nazivom svog projekta.

Domain

Entiteti. Ne zavisi ni od jednog projekta ni NuGet paketa.

Models/ → Entities/

Application

Commands, queries, handleri, validatori i DTO. Bazu podataka vidi samo kroz interfejs IAppDbContext.

Common/, Dtos/, Modules/

Infrastructure

AppDbContext, konfiguracije entiteta i migracije: sve što zna za SQL Server.

Data/, Migrations/ → Database/

API

Kontroleri, GlobalExceptionHandler i Program.cs. Kontroler samo šalje zahtjev: sender.Send(…).

Controllers/, Middleware/

Pravilo zavisnosti

Strelice idu prema Domain, nikad od njega

Strelica je ProjectReference: projekat na početku strelice vidi klase projekta na kraju. Kliknite projekat da vidite njegov .csproj na kraju nadogradnje.

Domain ne referencira nijedan projekat. Application ne referencira Infrastructure. Handler traži IAppDbContext, a AppDbContext ga implementira u Infrastructure. Obrnuta referenca bi bila kružna, a build je odbija (MSB4006, izmjereno).

Izmjereno na kopiji rješenja V04: sve komande s ovih slajdova izvršene redom (git, PowerShell, .NET SDK), build poslije svakog koraka 0 grešaka, 0 upozorenja. Nad bazom podataka napravljenom migracijama iz V04 (LocalDB) prošlo je 37/37 zahtjeva iz MojaApp.API.http.

Za nove migracije: --project MojaApp.Infrastructure --startup-project MojaApp.API. U Package Manager Consoleu je Default project MojaApp.Infrastructure, a startup projekat MojaApp.API.

Česte greške (izmjerene)

error MSB4006: There is a circular dependency in the target dependency graph …

Commit poslije svakog koraka

Prije prvog koraka napravite granu, npr. git switch -c clean-architecture. Poslije svakog koraka build mora proći, pa je jedan korak jedan commit. Ako korak ne uspije, vraćate se samo na prethodni commit.
