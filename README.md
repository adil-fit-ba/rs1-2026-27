# Razvoj softvera I – 2026/27

Repozitorij predmeta Razvoj softvera I (FIT, Univerzitet „Džemal Bijedić” u Mostaru), akademska 2026/27.

| Folder | Sadržaj |
|---|---|
| [`starter/`](starter/) | Starter projekat na kojem se radi seminarski rad: ASP.NET Core (.NET 8, Clean Architecture sa CQRS) i Angular |

Starter je ista verzija kao template projekat iz repozitorija [`adil-fit-ba/rs1-2025-26`](https://github.com/adil-fit-ba/rs1-2025-26) (commit `fcbcbdd`). Upute za pokretanje i screenshotovi su u [`starter/README.md`](starter/README.md).

Preduslovi za pokretanje: .NET 8 SDK, Node.js 22 ili 24 (LTS) i SQL Server na `localhost,1433` (connection string je u `starter/Market.Backend/Market.API/appsettings.json`).

Repozitorij klonirajte u kratak folder (npr. `C:\rs1`) i jednom uključite duge putanje: `git config --global core.longpaths true`.
